# Контекст проекта

Локальный просмотр карт из ангара для «Мир танков» RU 1.45.0.0 #2269.
Python 2.7 и Scaleform/AS3. Версия сборки по умолчанию задана в `build.ps1`.

Перед изменениями прочитай `README.md` и `docs/architecture.md`;
для интеграций — `docs/debug-panel-api.md`, для выпуска — `docs/release-checklist.md`.

## Окружение

- Игра: `E:\Games\Tanki`; исходники клиента: `E:\wot-mods\wot-src-ru`, ветка `mt-ru`.
- Python: `C:\Python27\python.exe`. Запускай с `-B`, чтобы не оставлять кэш
  рядом с исходниками; байткод пакета сборщик создаёт в `.build/`.
- Пути Royale и Java заданы в `build.ps1`, настройки редактора — в `.vscode/`.
- Команды извлечения библиотек, тестов и сборки приведены в README.
- Локальный REPL: `.local/repl_call.ps1` и `.local/repl-validation-helpers.ps1`.
  Параметры подключения не публикуй.

## Правила работы

- Для игровой разработки используй `wot-mod-development`. Новые клиентские
  контракты проверяй по `wot-src-ru`, поведение — через WotStat REPL.
- Управляй игрой и снимай скриншоты только через REPL, без системной мыши/клавиатуры.
- Используй штатные контролы; собственные ресурсы мода размещай под уникальными
  именами. Не изменяй исходники клиента, извлечённые SWC и оригинальные ресурсы игры.
- Сохраняй публичные API `debug_panel` и `events`. Внешние модели должны удаляться
  синхронно в `stopping`, до освобождения пространства.
- После изменений жизненного цикла проверяй повторный вход/выход, восстановление
  ангара, ввода и GUI, отсутствие оставшихся подписок и ошибок cleanup.
- Устанавливай пакет при закрытой игре в `mods/1.45.0.0/`, оставляя одну версию мода.
- Сохраняй стиль и короткую сборку; не добавляй незапрошенный рефакторинг.
- Логи, скриншоты, временные планы и результаты REPL храни в `.local/`.
  `.build/`, `dist/`, `as3/libs/` и Python-кэш также не входят в Git.
  В документации сохраняй текущие контракты и ограничения, а не историю отладки.
