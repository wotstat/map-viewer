# Отчёт о проверках

Дата: 7 сентября 2026. Клиент «Мир танков» RU 1.45.0.0 #2269,
`E:\Games\Tanki`, сервер входа RU1. Просмотр выполнялся локально из ангара.
Для наблюдения состояния и доставки клавиш / мыши использовался WotStat REPL 1.4.1.
Разрешение снимков — 2883×1714, масштаб интерфейса ×2.

Измерения движения приблизительные: клавиши доставлялись через REPL; измерение
общего времени вызовов включает накладные расходы. Направления, нормализация
диагонального движения и отсутствие дрейфа дополнительно проверены unit-тестами.

Диалог подтверждения проверялся через штатный `SettingsWindow.showWarningDialog`
при загруженной соответствующей вкладке. Графические настройки, требующие
перезапуска, не применялись. Цветокоррекция и гамма в штатных боевых настройках
отображаются недоступными. Esc в окне назначения клавиш передаётся штатному UI;
может закрыть окно настроек целиком. Сама камера при этом остаётся на паузе.

## Автоматические проверки

```text
C:\Python27\python.exe -B -m unittest discover -s tests -v
Ran 6 tests
OK
```

Проверены группировка карт и режимов, порядок очистки при ошибке одного шага,
движение относительно yaw / pitch, вертикаль мира, диагональная скорость и покой.
Оба AS3 адаптера собраны Apache Royale 0.9.12. Python скомпилирован Python 2.7.
CRC архива проверен; `.mtmod` содержит 13 файлов: метаданные, два собственных SWF
и собственные `.pyc`. Копий оригинальных игровых SWF, SWC и геометрии в нём нет.

Итоговый `.mtmod`: `wotstat.local-maps_1.0.0.mtmod`, 47 594 байта.
SHA-256: `d32552fa5197b036cc536d7bd9b3ae8d54576f1bf90c55c2f40f28c007d7cfcd`.
Архив в `dist` совпадает с установленным архивом.

После последней пересборки выполнен ещё один чистый запуск установленного архива:
Малиновка → меню → выход кнопкой → готовый ангар. В участке журнала от загрузки
карты до завершённого возврата ошибок нет. Состав GUI roots до и после совпал.
Игра после испытаний закрыта.
Машинные результаты: [runtime-validation.json](runtime-validation.json).
Сообщения мода из контрольного прогона: [client-validation.log](client-validation.log).

## Исправления, проверенные в клиенте

- Ангар освобождается штатным жизненным циклом до загрузки карты: два одновременно
  живых мира нарушали отрисовку земли и окружения.
- Перед возвратом камера отделяется от удаляемого пространства. Ангар загружается
  через штатный `HangarSpace.init()`; повторный вход блокируется до готовности танка.
- Скрытое lobby app деактивируется, чтобы не перехватывать ввод поверх просмотра.
- Для нативной боевой миникарты используется отдельный оригинальный `battle.swf`
  без второго Wulf MAIN_WINDOW.
- Справка зарегистрирована с динамической областью, требуемой `SimpleDialog`.
- Выход по кнопке отложен на следующий кадр: штатная кнопка успевает завершить
  обработку ввода и журналирование до удаления её movie.

## Объём проверки

Полная матрица всех 50 карт, всех режимов, видеорежимов и сочетаний сторонних модов
не проходилась. Потеря соединения и принудительное прерывание загрузки не
инъецировались в финальный прогон. Обработчики завершения предусмотрены в коде;
ошибка одного шага очистки проверена отдельным тестом.

Мод показывает установленную геометрию и статические точки из ArenaType.
Серверные сценарии, техника, физика боя и интерактивные объекты не запускаются.
