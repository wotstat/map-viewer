# Проверка версии 1.1.0

7 сентября 2026, «Мир танков» RU 1.45.0.0 #2269, RU1.
Архив установлен в `E:\Games\Tanki\mods\1.45.0.0\` и проверен после перезапуска.
SHA-256 `.mtmod`: `26debe3c60c747a687ac5aec002faa39b1821b9c182d2f4fccd446888f61d9fe`.
Окончательная сборка прошла два цикла: Вестфилд / `bob` (1376279) и
Арзагир 4.04 / `ctf` (97, служебная карта с explicitRequestOnly=True).

| Запрос | Результат |
|---|---|
| Режим над миникартой | Две колонки, средний пустой столбец убран; окно центрируется |
| Высота дропдауна | Сохранена: штатный CLIK DropdownMenu имеет `menuRowsFixed=True` |
| Загрузка карты | Оригинальный `waitingTransitionsApp.swf`, чёрный фон, штатная шестерёнка; тяжёлый запуск отложен на 0,15 с после готовности Flash |
| Граница карты | Оригинальный ArenaBorderHelper и контроллер настроек; проверены красные полосы у края Вестфилда |
| Затемнение и крестик Esc | Параметры исходного боевого окна: TOP_WINDOW, isModal=True, canClose=False, canDrag=False |
| Раздел «Управление» | Удалён штатным списком кнопок; остаются выход, настройки, возврат |
| Дополнительные карты и режимы | 65 установленных геометрий вместо 50, включая служебные; `bob` сохранён под исходным именем |
| Выход | Шестерёнка появляется до освобождения мира; затем восстанавливаются исходные Account, ангар, окружение, маска и танк |

Настройки открываются над меню; Esc из настроек возвращает к меню, следующий
Esc — к полёту. Камера в меню не движется. Параметры границы читаются из настроек
игры; сброс Alt при открытии меню предотвращает залипание временного показа.

Проверка отсутствующей картинки выполнена с временным локальным адаптером,
возвращающим отсутствие файлов только для компонента превью. Геометрия и записи
каталога при этом не менялись. Пустое название заменяется geometryName, неизвестный
перевод режима — gameplayName. Имеющаяся безымянная запись `1006_3d_styles_test`
не имеет установленного space.settings; несуществующая геометрия в каталог не входит.

Дополнительно проверены отказ конструктора экрана загрузки и отсутствие его
инициализации: оба сценария завершают cleanup, возвращают ввод и снимают active/stopping.
Таймаут — 10 секунд. Проверка кода покрыла поздний callback миникарты во время
выхода и немедленное освобождение ресурсов при смене Account/приложения.
Реальное отключение от сервера не воспроизводилось.

Сборка Python 2.7 / AS3 успешна, 6 существующих тестов прошли.
Оба возврата: cleanupErrors=0, все проверки совпадения состояния — true,
список GUI roots совпадает с исходным. Клиент закрыт после испытаний.
В ходе просмотра ошибок в журнале не было. При закрытии клиента штатный
`helpers/styles_perf_toolset/report_generator.py` записал два сообщения об
отсутствующей папке отчётов; они не относятся к просмотрщику.
Клиентские ресурсы не переопределяются и не копируются в архив мода.
Полная проверка всех 65 геометрий и серверных сценариев режимов не проводилась.
