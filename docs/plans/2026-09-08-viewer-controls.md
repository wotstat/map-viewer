# Управление интерфейсом просмотра карт

Добавить штатную кнопку «Назад в ангар» сверху слева, курсор по удержанию
любого Ctrl и расширяемую панель настроек снизу слева. Оставить оригинальные
клиентские ресурсы без подмены; проверять игру только через WotStat REPL.

Панель шириной около 300 логических пикселей: тёмный полупрозрачный фон,
заголовок, подсказка Ctrl, сворачиваемые секции, штатные Slider / CheckBox /
DropdownMenu. Ограничить высоту экраном и прокручивать длинное содержимое.
Первая секция «Свободная камера»: скорость 5–500 м/с. Колесо и слайдер
показывают одно значение. Точное движение переносится с Ctrl на C.

1. Реестр настроек (`debug_panel.py`, `tests/test_debug_panel.py`).
   Публичные registerSection / unregisterSection / setValue, отдельные ID
   секций и контролов, callback(controlID, value), проверка данных до изменения
   реестра, уведомление UI и изоляция ошибок callback. Проверить независимость
   секций, обновление значений и отклонение некорректных данных unit-тестами.
2. UI (`BattleBridge.as`, новые `DebugPanel.as` / `DebugControl.as`).
   Подключить BackButtonUI, оригинальные контролы и полосу прокрутки. Создавать
   секции из описаний реестра, обновлять значения без пересоздания слайдера.
   Закрывать выпадающие списки и завершать перетаскивание при отключении ввода.
3. Интеграция (`bootstrap.py`, `viewer.py`, `flight.py`, `battle_app.py`).
   Подключить библиотеки к локальному battle app. Отделить Ctrl от паузы меню,
   замораживать камеру и направлять ввод в GUI при курсоре, учитывать оба Ctrl.
   Восстановить режим мыши при отпускании Ctrl, меню и выходе. Возврат через
   существующий экран загрузки. Удалять подписку HUD на реестр при уничтожении.
4. Сборка, REPL и документация.
   Собрать 1.3.0 существующим build.ps1. Проверить реальную кнопку, Ctrl / оба
   Ctrl, слайдер и колесо, добавление/удаление сторонней секции со всеми типами
   контролов, раскрытие/прокрутку, меню, возврат и повторный вход. Проверить
   компактный экран и отсутствие ошибок за интервал проверки. Описать API
   с работающим примером, обновить README и исходный архив.
