# Настройки других модов в просмотрщике карт

Модуль `gui.mods.wotstat_map_viewer.debug_panel` предоставляет API секций настроек.
Секция может регистрироваться при загрузке другого мода либо во время просмотра.
Панель обновится автоматически. Курсор включается удержанием Ctrl.
Новые группы по умолчанию свёрнуты. Группа раскрывается нажатием
на строку заголовка. Обновление секций сохраняет
состояние существующих групп; при новом входе в просмотр все группы свёрнуты.
Скроллбар находится внутри панели и при появлении уменьшает ширину групп.
Панель содержит внешние секции, динамические события на подходящих картах WoT EU
и выбор сцены в стандартном ангаре WoT EU. При пустом реестре она полностью скрыта;
регистрация первой секции показывает её, удаление последней — скрывает.
При скрытом через V интерфейсе новые секции появятся после его включения.
Текст автоматически переносится по оставшейся ширине.

Собственные заголовки просмотрщика следуют языку клиента. Названия секций,
подписи контролов, варианты и подсказки API принимает как готовый текст:
интеграция переводит их сама, ориентируясь на `helpers.getClientLanguage()`.
Просмотрщик не заменяет и не переводит переданные строки автоматически.

```python
# coding: utf-8
from gui.mods.wotstat_map_viewer import debug_panel

SECTION = 'my.mod.render-tools'  # Уникальное пространство имён вашего мода.
values = dict(enabled=True, intensity=50.0, quality='medium')

def onChange(controlID, value):
    values[controlID] = value
    # Примените настройку своего мода здесь.

debug_panel.registerSection(SECTION, u'Инструменты рендера', [
    dict(id='enabled', type='checkbox', label=u'Включено', value=True),
    dict(id='intensity', type='slider', label=u'Интенсивность',
         value=50.0, min=0.0, max=100.0, step=1.0, suffix=u' %'),
    dict(id='quality', type='dropdown', label=u'Качество', value='medium',
         options=[dict(label=u'Низкое', value='low'),
                  dict(label=u'Среднее', value='medium'),
                  dict(label=u'Высокое', value='high')])
], onChange)
```

`onChange(controlID, value)` вызывается при изменении пользователем. Выполняйте
вызовы API и обработчики в главном потоке клиента; длительную работу в обработчике
не выполняйте. Повторный выбор того же значения не вызывает обработчик.

Параметры контрола:

| Поле | Значение |
|---|---|
| `id` | Непустой строковый ID, уникальный внутри секции |
| `type` | `slider`, `checkbox`, `dropdown`, `timeline` или `text` |
| `label` | Подпись; для русского текста используйте Unicode |
| `value` | Начальное значение |
| `min`, `max` | Для слайдера: конечные числа, `min < max` |
| `step` | Для слайдера: положительный шаг ручного изменения, по умолчанию 1 |
| `suffix` | Для слайдера: единица после значения, по умолчанию пустая строка |
| `options` | Для списка: непустой список `{label, value}` с уникальными значениями |
| `tooltip` | Необязательный текст подсказки при наведении |
| `text` | Для текстовой строки: непустой произвольный текст, переносы строк поддерживаются |
| `color` | Для текстовой строки: RGB-число `0x000000`–`0xFFFFFF`, по умолчанию `0xC9C9B6` |
| `playTooltip`, `pauseTooltip` | Для `timeline`: подсказки кнопки воспроизведения, по умолчанию пустые |

Значение чекбокса — `bool`. Значение слайдера — число в указанном диапазоне.
Значения вариантов списка — строки, логические значения либо конечные числа.
Обработчик списка получает значение выбранного варианта, а не его индекс.
Некорректная регистрация вызывает `ValueError` и сохраняет предыдущую секцию.
Повторная регистрация того же ID заменяет её описание и обработчик.

`timeline` — шкала 0–100% со штатной кнопкой Play/Pause. Её значение — словарь
`dict(position=0.0, playing=False)`. `position` — конечное число от 0 до 100,
`playing` — `bool`. Ручное изменение позиции передаёт `playing=False`, нажатие
кнопки меняет `playing`, сохраняя позицию. Даже начало перетаскивания без изменения
процента ставит играющий timeline на паузу. Владелец контрола выполняет
воспроизведение и повторный запуск после 100%, обновляя оба поля через `setValue`.
Контрол сам не ведёт часы. Подпись переносится по ширине строки; шаг ручного
изменения — 0,1%. Словари значений копируются при приёме и чтении.

Если настройка изменилась другим способом, примените её у себя и обновите панель:

```python
values['intensity'] = 75.0
debug_panel.setValue(SECTION, 'intensity', values['intensity'])
current = debug_panel.getValue(SECTION, 'intensity')
```

`setValue` проверяет значение и обновляет UI без вызова `onChange`, чтобы избежать
обратных вызовов по кругу. Дробные значения допустимы и при целочисленном шаге:
шаг задаёт ручное изменение слайдера, а программное значение сохраняется точно.
Неизвестный ID при `getValue` / `setValue` вызывает `KeyError`.

При отключении своего мода удалите секцию, чтобы освободить обработчик:

```python
debug_panel.unregisterSection(SECTION)
```

Удаление отсутствующей секции ничего не делает. Ошибка в пользовательском
обработчике записывается в лог, значение контрола возвращается к предыдущему;
остальные секции продолжают работать. Откат внешних действий обработчика
остаётся ответственностью его владельца.

Секции и значения сохраняются между открытиями просмотрщика в текущем процессе.
Сохранение на диск остаётся за модом, которому принадлежит настройка.

## Подсказки и текстовые строки

`registerSection` принимает необязательный именованный аргумент `tooltip` для
подсказки заголовка секции. Поле `tooltip` у элемента добавляет его собственную
подсказку. Они видны при удержании Ctrl и закрываются при выключении ввода,
прокрутке, сворачивании или удалении секции.

```python
debug_panel.registerSection('my.legend', u'Легенда', [
    dict(id='red', type='text', text=u'Красный — 0% маскировки', color=0xFF6666),
    dict(id='help', type='text', text=u'Произвольный текст\nна нескольких строках')
], lambda controlID, value: None, tooltip=u'Пояснение раздела')
```

Текст переносится по ширине панели и участвует в прокрутке. Это обычный текст,
не HTML. У строки `text` нет `label` и `value`; она не вызывает `onChange`.
`getValue` для неё вызывает `KeyError`, `setValue` — `ValueError`. Для изменения
текста зарегистрируйте секцию повторно.

## События просмотра

Модуль `gui.mods.wotstat_map_viewer.events` позволяет подключить визуализацию
без импорта внутреннего `LocalSession` и без создания боевого Avatar.

```python
from gui.mods.wotstat_map_viewer import events

def onViewer(event, context):
    if event == 'ready':
        # Геометрия и HUD готовы; модели добавляются в context.spaceID.
        pass
    elif event == 'stopping':
        # СИНХРОННО отмените callbacks и удалите свои модели.
        # Пространство ещё существует, но getContext() уже возвращает None.
        pass
    elif event == 'stopped':
        # Возврат завершён (в том числе прерванный сменой аккаунта).
        pass

events.subscribe(onViewer)
context = events.getContext()  # None вне готового просмотра.
if context is not None:        # Подключение после ready поддерживается явно.
    onViewer('ready', context)
# При отключении мода: сначала очистка своих ресурсов, затем
# events.unsubscribe(onViewer).
```

`context` — неизменяемый `ViewerContext` с полями `spaceID`, `arenaID`,
`geometryName`, `gameplayID`, `visibilityMask`. Для просмотра ангара `arenaID` и
`gameplayID` равны `None`, а `geometryName` содержит имя ангарного пространства.
Подписка идемпотентна, ошибки
одного слушателя логируются и не прерывают остальных. События посылаются один раз
на готовый просмотр: `ready` → `stopping` → `stopped`. Если загрузка не дошла до
готовности, этих событий нет. Подписки живут до явного удаления; ресурсы мира
должны жить только между `ready` и `stopping`.
