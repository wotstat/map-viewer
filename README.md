# Локальный просмотр карт

Общий мод для «Мир танков» RU 1.45 и World of Tanks EU 2.4: открывает карты из ангара без создания боя
или тренировочной комнаты. Свободная камера, штатная миникарта с точками режима,
игровое меню и настройки. При выходе восстанавливается исходный ангар.

## Установка

1. Закройте игру и скопируйте пакет в каталог нужного клиента:
   - «Мир танков»: `wotstat.map-viewer_1.6.0.mtmod` в `mods/1.45.0.0/`;
   - World of Tanks: `wotstat.map-viewer_1.6.0.wotmod` в `mods/2.4.0.0/`.
   Оставьте только одну версию мода. Пакеты побайтово одинаковы и различаются
   только расширением; клиентские API выбираются при запуске.
2. В ангаре нажмите **F8** или выберите **«Локальный просмотр карт»** в ModsList.
3. Выберите карту и режим, нажмите **«Начать просмотр»**.
4. Для выхода нажмите **Esc → «Выйти в ангар»** или удерживайте **Ctrl**
   и нажмите **«Назад в ангар»**.

ModsList и REPL для работы не требуются. Для удаления уберите `.mtmod` или `.wotmod`
при закрытой игре. Мод не заменяет базовые файлы игры.

## Управление

| Действие | Клавиши |
|---|---|
| Горизонтальный полёт | W / A / S / D |
| Подъём / спуск | Space или E / Shift или Q |
| Направление взгляда | Мышь |
| Скорость 1–500 м/с | Колесо мыши |
| Скорость 1, 2, 5, 10, 15, 20, 30, 50, 75 м/с | Цифры 1–9 |
| Зум; колесо регулирует увеличение | Удерживать Z |
| Курсор для кнопок и настроек | Удерживать Ctrl |
| Точное движение (×0,25) | Удерживать C |
| Размер миникарты | + / − в основном ряду |
| Показать / скрыть миникарту | M |
| Показать / скрыть интерфейс | V |
| Меню, настройки, выход | Esc |
| Временный показ границы, если выбран в настройках | Alt |

Движение плавное, без столкновений с землёй и зданиями. WASD сохраняют высоту
независимо от наклона взгляда. При Ctrl камера перестаёт принимать ввод,
инерция плавно затухает; в меню движение останавливается сразу.
Меню Esc доступно и при скрытом интерфейсе.

Другие моды могут добавлять секции настроек через [публичный API](docs/debug-panel-api.md).
Панель появляется при наличии секций; для работы с ней удерживайте Ctrl.
`wotstat-vegetation` использует её для отображения коллизий растительности.

На картах **World of Tanks EU** с динамическими событиями появляется раздел
«Динамические события». Для каждого события доступен слайдер 0–100% и кнопка
Play/Pause. Перетаскивание ставит событие на паузу в выбранном месте; Play
продолжает воспроизведение, а после 100% запускает его заново. Миникарта показывает
зоны события и разрушения в соответствии с выбранным временем, включая перемотку
назад. Для управления удерживайте Ctrl. Имена отдельных событий в клиенте
не локализованы: используются подписи «Событие N: технический идентификатор».
В «Мире танков» этот раздел не включается.

## Язык интерфейса

Язык автоматически совпадает с языком клиента. Поддерживаются русский,
английский, польский, немецкий, чешский, украинский, французский, испанский,
итальянский, турецкий и венгерский. Для остальных языков используется английский.
После смены языка игры перезапустите клиент.

Переведены окно выбора, кнопка возврата, меню Esc, заголовок панели и ModsList.
Названия карт и режимов берутся из локализации игры. Тексты секций других модов
переводят сами эти моды.

## Сборка

Нужны Python 2.7, Apache Royale 0.9.12, OpenJDK 21 и `playerglobal.swc`
для Flash Player 17 в `<Royale>/frameworks/libs/player/17.0/`.
Пути Python, Royale и Java задаются параметрами `-Python`, `-Royale` и `-JavaHome`
в `build.ps1`; значения по умолчанию подходят для локального окружения разработки.

Из корня проекта (путь к игре замените своим):

```powershell
C:\Python27\python.exe -B tools\extract_libraries.py E:\Games\Tanki
C:\Python27\python.exe -B -m unittest discover -s tests -v
.\build.ps1
C:\Python27\python.exe -B tools\source_archive.py 1.6.0
```

Библиотеки SWC уже находятся в `as3/libs` и входят в репозиторий.
Извлечение нужно только для обновления библиотек под другой клиент; команда
перезаписывает сохранённые SWC, поэтому изменения следует проверить перед коммитом.
Сборка создаёт `dist/wotstat.map-viewer_1.6.0.mtmod` и такую же копию `.wotmod`;
`-Version` переопределяет версию обоих пакетов. Для сборки на библиотеках WoT
передайте его каталог в `extract_libraries.py`. Игровые библиотеки используются как внешние зависимости
и в пакет не входят.

## CI/CD

Workflow `.github/workflows/release.yml` запускается при отправке тега с версией
без префикса (например, `1.6.1`) и вручную через Actions → release → Run workflow.
При ручном запуске версия задаётся в том же формате.

Windows runner устанавливает Python 2.7, Java 21 и Royale 0.9.12, запускает тесты
и `build.ps1`. Клиентские SWC берутся из репозитория; `tools/setup_ci.ps1`
скачивает Royale и Flash Player 17 API с проверкой контрольных сумм.
Установленная игра и отдельный runner не требуются.

Оба пакета доступны как Actions artifacts. Запуск по тегу также создаёт GitHub
prerelease и прикладывает `.wotmod` и `.mtmod`; ручной запуск только собирает
артефакты. Для публикации используется штатный `GITHUB_TOKEN` с `contents: write`.
Игровую проверку перед выпуском нужно выполнять отдельно.

Для разработки: [архитектура](docs/architecture.md),
[API интеграций](docs/debug-panel-api.md), [проверка выпуска](docs/release-checklist.md).
