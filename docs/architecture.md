# Архитектура

Мод загружает клиентскую геометрию без серверного боя и Avatar.
Python-код находится в `res/scripts/client/gui/mods/`, AS3 — в `as3/src/wotstat/mapviewer/`.

## Основные модули

| Модуль | Ответственность |
|---|---|
| `mod_wotstat_map_viewer.py`, `bootstrap.py` | Загрузка мода, F8, ModsList, окно выбора |
| `catalog.py`, `preview.py` | Карты и режимы из `ArenaType`, штатное превью |
| `viewer.py`, `cleanup.py` | Сессия просмотра, переходы и восстановление ангара |
| `flight.py` | Движение камеры, скорость и зум |
| `battle_app.py`, `ui_routing.py` | Локальное battle app, меню, настройки и маршрутизация окон |
| `loading.py`, `border.py`, `space_hooks.py` | Экран перехода, граница карты, адаптация UDO |
| `minimap_bounds.py`, `minimap_points.py` | Границы текстуры и точки выбранного режима |
| `debug_panel.py`, `events.py` | Публичные настройки и события для других модов |
| `dynamic_events.py` | Локальные шкалы времени сценарных событий WoT EU |
| `MapBridge.as`, `MapSelector.as` | Мост ангарного UI и окно выбора карты |
| `BattleBridge.as`, `DebugPanel.as`, `DebugControl.as`, `DebugTooltip.as` | HUD и панель настроек |
| `NativeControls.as` | Подключение общих штатных библиотек контролов |
| `localization.py` | Собственные переводы UI и выбор языка клиента |

## Жизненный цикл

Каталог группирует `ArenaType.g_cache` по геометрии и оставляет режимы с установленным
`space.settings`. После карт он добавляет пространства с `space.settings/hangarSettings`
из ресурсов клиента. Маску видимости карты даёт `SpaceVisibilityFlagsFactory`, для
ангара используется штатный `getHangarFullVisibilityMask`. Ангары запускаются без
превью миникарты, боевой границы и динамических событий.

`LocalSession` сохраняет Account, танк, окружение ангара, FOV и состояние ввода/UI.
Для карт и ангаров MT после `HangarSpace.destroy()` создаёт собственное пространство
и загружает геометрию через `addSpaceGeometryMapping()`. Ангары WoT EU используют
штатный `HangarSpace`: их CGF-сценарии обращаются к его ID и камере. При выборе
другого ангара путь временно меняется через `g_clientHangarSpaceOverride`, а
конфигурация ангара из модов при необходимости регистрируется из `hangarSettings`.
После просмотра исходный путь и прежнее переопределение восстанавливаются.
Мир отображает `BigWorld.FreeCamera`.
`LoadingCover` использует независимый Flash root со штатным `WaitingTransition`,
который переживает смену приложений; таймаут прерывает незавершённый переход.

Готовность геометрии и HUD вызывает `ready`. Перед очисткой вызывается `stopping`:
внешние моды должны синхронно убрать модели и callbacks. `CleanupStack` выполняет
обратные действия, продолжая очистку при ошибке отдельного шага. Удаляется только
собственное пространство; `HangarSpace.init()` восстанавливает ангар после карты,
а в WoT EU сменённый ангар возвращается штатным `refreshSpace()`. Новый вход
блокируется до готовности ангара и танка. `stopped` завершает цикл событий.
Контракт прерванной загрузки и поля контекста описаны в [API](debug-panel-api.md).

## UI и ввод

Селектор наследует `AbstractWindowView` и использует штатные `Window`, список,
dropdown и `MinimapLobby`. Боевой HUD работает в отдельном `battle.swf` через
`GUI.Flash` с менеджерами `BattleEntry`/`AppEntry`. Адаптер корня заменяет фабрику
`MainWindow` только в локальной копии функции: второй Wulf `MAIN_WINDOW`
конфликтует с областями основного окна. `BattleGameInputMgr` требует Avatar
и здесь не создаётся.

Селектор пересчитывает размер `MinimapLobby` после каждой загрузки текстуры:
постоянный обработчик `UILoaderEvent.COMPLETE` дополняет одноразовый штатный
обработчик и удаляется при закрытии окна.

Миникарта, значки, меню Esc и настройки используют штатные компоненты.
Маршрутизация дочерних окон временно направляется в локальное battle app
и восстанавливается при выходе. Ангарный и боевой AS3-код разделены по movie.
`NativeControls` загружает `guiControlsLoginBattle.swf` и
`guiControlsLobbyBattle.swf` из установленного клиента. Собственный `ReturnButton`
наследует штатный `SoundButton`, сохраняя обработку ввода и звуков. Текст, стрелка
и подсветка воспроизводят оформление ангарной кнопки возврата.
Копия кода `lobby.swf` в боевой movie не загружается:
она дублирует весь банк ангарных классов и существенно увеличивает расход памяти
Scaleform. Игровой код и библиотеки в пакет не включаются.

Ctrl включает `GUI_ENABLED` и отключает ввод камеры с плавным затуханием инерции.
Отпускание обоих Ctrl возвращает `CURSOR_ATTACHED`; курсор синхронизируется
через `CursorManager.resetMousePosition`. Меню и потеря фокуса останавливают
движение. Перед удалением контролов или отключением ввода фокус возвращается
на HUD, dropdown закрывается. M/V управляют видимостью миникарты и HUD;
новый просмотр сбрасывает эти флаги.

Реестр секций сохраняется между просмотрами; HUD отписывается от него при уничтожении.
Встроенная секция динамических событий живёт только в текущем просмотре WoT EU.
Внешние интеграции, включая vegetation, используют
только [публичный API](debug-panel-api.md).

## Динамические события WoT EU

В списке карт отметка справа использует наличие `ArenaType.minimapLayers` в EU,
исключая варианты `*_sm24` и `*_sm25`. Это предварительный признак из ресурсов
карты; контролы появляются только после обнаружения сценариев в загруженном CGF.

`DynamicEvents` создаётся после готовности геометрии и миникарты. В текущем
CGF-пространстве он находит корневые `<event>_scenario` с `GenericComponents.Sequence`.
Сценарные варианты `*_sm24` и `*_sm25` исключены. В MT контроллер не обращается
к WoT-компонентам; выбор продукта использует `constants.AUTH_REALM`.

Один корневой sequence управляет дочерними complete/normal/transition/destroyed
объектами и их задержками. Контроллер не перематывает детей независимо: их
длительности и смещения различаются. Процент отсчитывается от длительности
корневого сценария. `pause()` + `requestTime()` задают положение; оно считается
применённым после подтверждения фактического времени на следующем CGF-тике.
Только затем вызывается `start()`, если запрошено воспроизведение. Обновление UI
идёт каждые 50 мс через `debug_panel.setValue`, без повторного вызова обработчика.
Повторный Play на 100% сначала перематывает к нулю. При ошибке сценария контроллер
отключает секцию, отменяет callback и очищает свои ссылки и слои.

`LocalMinimap` регистрирует штатные слои `arena.minimapLayers` через
`as_setScenarioEventS`. Их видимость следует активности связанных CGF-объектов с
`UIComponents.MinimapChangerComponent.layerId`; слой не привязывается к условному
процентному порогу. Связь определяется по ID слоя из метаданных карты, а не по
имени объекта: префиксы компонентов и сценария могут различаться.
Несколько активных компонентов одного слоя объединяются.
Перемотка назад скрывает завершённые слои, а вход начинается с 0%.
Отдельных локализованных имён событий клиент не предоставляет: подпись содержит
локализованное «Событие N» и исходный ID без интерпретации его смысла.

Контроллер очищается после `stopping`, до удаления HUD и пространства через
`CleanupStack`: callback отменяется, корневые sequence ставятся на паузу, секция
и слои удаляются, ссылки на CGF-объекты освобождаются. Пространство и дочерние
ресурсы сценария затем уничтожаются штатной очисткой просмотра.
Произвольная перемотка воспроизводит геометрию и переключения видимости, но
не обещает обратимость одноразовых звуков, частиц и создания дополнительных prefab.

Собственные строки хранятся в `localization.py`: язык выбирает штатный
`helpers.getClientLanguage()` из локализации клиента. Региональные суффиксы
нормализуются; для неподдерживаемого языка используется английский.
Python передаёт строки в селектор и HUD вместе с их начальными данными;
меню Esc и ModsList используют тот же словарь. Переводы не дублируются в AS3.
Кнопка возврата рассчитывает ширину надписей и области клика по тексту;
заголовок панели уменьшает шрифт, если перевод не помещается.
Названия карт и режимов по-прежнему берутся из клиента, внешние секции
получают готовые переведённые строки от интеграции.

## Совместимость клиентов

Один Python/AS3-код и один архив используются в MT и WoT. Сборщик копирует
готовый `.mtmod` в `.wotmod` без изменения содержимого. Общие библиотеки контролов
загружаются из установленного клиента во время работы.

Различия API обрабатываются в местах вызова:

- `battle_app` выбирает `R.entries.battle` (MT) или `R.entries.default.battle` (WoT);
- `LocalMinimap` отключает подсказку через клиентский Python `MinimapMeta`:
  `as_disableHintPanelS(True)` в MT и `as_disableHintPanelS()` в WoT;
- `space_hooks` устанавливает исправление только при наличии MT `SoundZoneTrigger`;
- `viewer` сохраняет объект `BigWorld.Space` в WoT и передаёт его числовой `id`
  в операции с пространством; в MT `createSpace()` сразу возвращает число;
- нативная миникарта использует `GUI.MinimapFlashAS3` / `inputKeyMode` в MT
  и `GUI.WGMinimapFlashAS3` / `wg_inputKeyMode` в WoT;
- `loading` передаёт экрану перехода текущие размеры и эффективный масштаб,
  используя общий API `interfaceScale.get()`;
- `viewer` сравнивает окружение ангара только у клиентов с этим свойством;
- `catalog` использует общий путь иконки без удалённого в WoT training formatter.

## Контракты для переноса на новый патч

Проверяй в исходниках обоих клиентов: `wot-src-ru`, ветка `mt-ru`, и
`wot-src-eu`, ветка `wot-eu`:

- `gui/ClientHangarSpace.py`, `gui/shared/utils/HangarSpace.py` — восстановление
  ангара, окружения и маски видимости; `helpers/OfflineMode.py` — пространство и камера.
- `gui/Scaleform/framework/application.py`, `battle_entry.py` — Flash root и DAAPI;
  `SettingsWindow.py`, `framework/package_layout.py` — меню и маршрутизация окон.
- `gui/Scaleform/daapi/view/battle/shared/minimap/component.py` — миникарта;
  `story_mode/gui/scaleform/daapi/view/battle/minimap.py` — квадратные границы
  текстуры прямоугольной карты. Граница мира остаётся исходным прямоугольником.
- `ArenaBorderController` / `ArenaBorderHelper` — граница с ID локального пространства.
- `SoundZoneTrigger.__init__` — создаёт CGF-объект в `player().spaceID`, который
  у Account равен 0. `space_hooks` использует локальную копию конструктора
  с CGF-фасадом, подставляющим ID просмотра; глобальный CGF не заменяется.

Сценарии регрессии: [проверка выпуска](release-checklist.md).
