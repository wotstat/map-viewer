# Библиотеки сборки AS3

SWC сохранены в репозитории, чтобы локальная сборка и CI использовали один набор
зависимостей. Это набор, на котором собрана и проверена версия мода 1.6.0 в WoT EU 2.4.

Все библиотеки подключаются через `external-library-path`: их код не встраивается
в SWF и они не копируются в `.wotmod` или `.mtmod`. При запуске используются классы
из установленного клиента игры.

Для обновления используйте `tools/extract_libraries.py <каталог игры>` из корня
проекта. После обновления проверьте сборку и совместимость с обоими клиентами.
Отдельная зависимость компилятора `playerglobal.swc` для Flash Player 17 по-прежнему
ожидается в `frameworks/libs/player/17.0/` выбранного Royale SDK.
