# Локальный просмотр карт — «Мир танков» RU 1.45

Просмотр установленной геометрии карт из ангара без создания боя или тренировочной
комнаты. Мод разработан с нуля по клиентским исходникам RU 1.45.

## Установка и запуск

1. Закройте игру.
2. Скопируйте `dist/wotstat.local-maps_1.4.3.mtmod` в
   `E:\Games\Tanki\mods\1.45.0.0\`. Оставьте только одну версию этого мода.
3. В ангаре нажмите **F8** или выберите **«Локальный просмотр карт»** в ModsList.
4. Выберите карту слева, режим в списке справа и нажмите **«Начать просмотр»**.
5. Для выхода зажмите **Ctrl** и нажмите **«Назад в ангар»** сверху слева.
   Выход через **Esc → «Выйти в ангар»** также доступен.

REPL и ModsList для работы не обязательны. Для удаления достаточно убрать
единственный `.mtmod` при закрытой игре. Базовые файлы игры мод не заменяет.

На испытательном компьютере новый архив уже установлен. Ранее установленный
`wotstat.map-viewer_1.0.0.mtmod` сохранён отдельно в
`.local/original-mods/`, чтобы два просмотрщика не работали одновременно.

## Управление

| Действие | Клавиши |
|---|---|
| Полёт вперёд / назад | W / S |
| Полёт влево / вправо | A / D |
| Подъём / спуск по вертикали мира | Space или E / Shift или Q |
| Направление взгляда | Мышь |
| Скорость, от 1 до 500 м/с | Колесо мыши без Z |
| Предустановки скорости: 1, 2, 5, 10, 15, 20, 30, 50, 75 м/с | Цифры 1–9 |
| Зум ×3; колесо регулирует увеличение | Удерживать Z |
| Курсор для кнопок и настроек | Удерживать левый или правый Ctrl |
| Точное движение | C ×0,25 |
| Размер миникарты | + / − в основном ряду клавиатуры |
| Показать / скрыть миникарту | M |
| Показать / скрыть весь интерфейс просмотра | V |
| Меню, настройки, выход | Esc |
| Временный показ границы, если выбран в настройках игры | Alt |

WASD сохраняют высоту независимо от наклона взгляда. Разгон и торможение плавные,
как в debug-utils; вертикальная скорость ограничена отдельно.
При удержании Ctrl ввод камеры отключается, движение по инерции плавно затухает.
В меню и окнах камера сразу останавливается. При освобождении ввода зум сбрасывается.
Управление камерой фиксированное;
штатное окно настроек изменяет настройки игры. Геометрия просматривается свободно,
без столкновений камеры с землёй и зданиями.

Во время вращения камеры скрытый курсор фиксируется в центре; нажатие Ctrl
показывает его там же. Без Ctrl панель параметров имеет непрозрачность 60%,
при удержании Ctrl — 100%. V сохраняет выбранную через M видимость миникарты.
Меню по Esc доступно и при скрытом интерфейсе; в меню M/V не переключают HUD.
При новом входе в просмотр миникарта и интерфейс снова включены.

## Компоненты

- Выбор карты: собственное окно со штатными списком, выбором режима, превью и кнопками.
- HUD: оригинальная боевая миникарта, сетка, значки баз / нейтральной точки и камеры.
- Шапка: штатная кнопка «Назад в ангар», название карты и режима.
- Панель слева снизу: полупрозрачный фон, сворачиваемые секции, штатные слайдеры,
  чекбоксы и списки, подсказки секций и элементов, текстовые строки с цветом.
  Группы изначально свёрнуты. Нажатие на крупный заголовок со стрелкой слева
  раскрывает или сворачивает содержимое под ним. Рамок вокруг групп нет.
  Длинное содержимое прокручивается. Другие моды могут добавлять
  настройки через [публичный API](docs/debug-panel-api.md).
  Панель появляется только при наличии внешних секций; встроенной секции камеры нет.
- Esc: оригинальное боевое меню с затемнением и штатные настройки.
- Граница: оригинальный игровой рендер, цвет, тип и режим видимости из настроек игры.
- Вход и выход: чёрный экран со штатной шестерёнкой до начала загрузки/освобождения мира.
- Выход восстанавливает исходный ангар, танк, окружение, FOV и ввод.

Каталог показывает карты и варианты режимов из установленного клиента, а не
текущую серверную ротацию. Серверные сущности, боты, разрушаемые объекты боя,
захват баз и сценарии режимов не моделируются. Это просмотр геометрии.
Проверены Вестфилд, Малиновка, Арзагир 4.04, Одер и Западный вал;
полная проверка всех карт и режимов не проводилась.
Служебные карты включены. Если перевода нет, показан технический идентификатор;
отсутствие картинки миникарты не мешает загрузке геометрии. Высота списка режимов
автоматически соответствует числу вариантов. Прямоугольные карты сюжетного режима
используют полные границы текстуры миникарты по штатному расчёту игры.

## Коллизии растительности

При установленном `wotstat-vegetation` 1.2.0 появляется секция «Растительность».
«Значащие кусты» показывает маскирующие коллизии, «Немаскирующие кусты» —
коллизии без эффекта маскировки. Чекбоксы независимы и выключены при каждом входе.
Удерживайте Ctrl и наведите курсор на заголовок или чекбокс для пояснений.
Легенда: красный — 0%, жёлтый — 25%, зелёный — 50% маскировки.
При выходе все коллизии выгружаются. Без vegetation просмотрщик работает отдельно.

В использованной среде:

- Python 2.7: `C:\Python27\python.exe`;
- Apache Royale 0.9.12: `%LOCALAPPDATA%\Programs\ApacheRoyale\0.9.12\royale-asjs`;
- OpenJDK 21: `%LOCALAPPDATA%\Programs\MicrosoftOpenJDK\21`;
- `playerglobal.swc` для Flash Player 17:
  `<Royale>\frameworks\libs\player\17.0\playerglobal.swc`.

SWC игры не входят в исходный архив. Извлечение читает ресурсы клиента, не меняя их:

```powershell
C:\Python27\python.exe tools\extract_libraries.py E:\Games\Tanki
.\build.ps1 -Version 1.4.3
C:\Python27\python.exe -B -m unittest discover -s tests -v
C:\Python27\python.exe -B tools\source_archive.py 1.4.3
```

Для другой установки SDK / Java измените пути в `build.ps1`.
AS3 компилируется с внешними игровыми библиотеками; оригинальные игровые классы
и ресурсы в мод не копируются. `.mtmod` содержит Python 2.7 bytecode и три
небольших собственных SWF под собственными именами.

Проверочная версия клиента: **1.45.0.0 #2269**. Перенос на другие патчи требует
повторной проверки клиентских контрактов.
